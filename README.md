# EV Charging Station Utilization & Profitability Analytics

## 📊 Project Overview

This project analyzes EV charging station performance using Microsoft Power BI.

The objective is to understand charging demand, station utilization, revenue generation, operating costs, and profitability across different cities, charger types, and customer segments.

The project uses a deliberately messy dataset to simulate a real-world analytics workflow, including data cleaning, data modeling, DAX measure development, and interactive dashboard design.

---

## 🎯 Business Objectives

The analysis focuses on answering key business questions:

* How much revenue and profit are generated by the charging network?
* What is the overall profit margin?
* How many charging sessions are completed, cancelled, or failed?
* Which cities generate the highest revenue and profit?
* Which charging stations are the most profitable?
* Which charger types perform best?
* What is the average energy consumption per session?
* What is the average session duration?
* How effectively are charging stations being utilized?
* Which areas or charger types may require further investigation?

---

## 🗂️ Dataset

The project contains approximately 5,000 EV charging session records covering 2024–2025.

The dataset includes:

* Session duration

* Price per kWh
* Revenue

* Maintenance cost

* Profit
* Occupancy rate
* Customer rating

The raw dataset intentionally contains real-world style data-quality issues such as missing values, inconsistent text formatting, whitespace, and duplicate records.

## 🧹 Data Cleaning

Power Query was used to prepare the dataset for analysis.

Key cleaning activities included:

* Removing duplicate records
* Handling missing values
* Trimming unnecessary whitespace
* Standardizing inconsistent text values
* Correcting data types
* Preparing dimension tables
* Validating numerical fields

Missing revenue values were handled using the average revenue for the project.

Missing customer ratings were treated as unavailable rather than representing them as genuine zero ratings.

## ⭐ Data Model

The Power BI model follows a **star schema**.

### Fact Table

**FactCharging**

Contains individual charging-session transactions and measurable business metrics.

Examples:

* Session_ID
* Session_Date
* Station_ID
* Energy_Consumed_kWh
* Revenue
* Electricity_Cost
* Maintenance_Cost
* Other_Cost
* Profit
* Session_Duration_Hours
* Occupancy_Rate_Pct

### Dimension Tables

**DimDate**

* Date
* Year
* Month
* Year-Month
* Quarter
* Weekday
* Weekend indicator

**DimStation**

* Station_ID
* City
* State
* Station Ownership

**DimCharger**

* Charger Type
* Connector Type

**DimCustomer**

* Customer Type
* Payment Method

The dimension tables connect to the fact table using one-to-many relationships.
